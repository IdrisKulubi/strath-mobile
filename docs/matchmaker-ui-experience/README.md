# Matchmaker UI Experience

This folder breaks the homepage matchmaker redesign into implementation phases.

The backend is now capable of:

- conversation sessions,
- LLM provider fallback,
- session-aware candidate search,
- feedback memory,
- structured profile intelligence,
- quotas,
- analytics.

The UI should now catch up and make that backend feel like a premium guided dating experience.

## Phase Order

1. `phase-01-conversation-home-foundation.md`
2. `phase-02-candidate-presentation.md`
3. `phase-03-feedback-and-memory-ui.md`
4. `phase-04-states-and-limits.md`
5. `phase-05-profile-decision-continuity.md`
6. `phase-06-motion-polish-accessibility.md`
7. `phase-07-admin-qa-rollout.md`

Build one phase, test it, then move to the next.
