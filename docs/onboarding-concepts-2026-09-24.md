# Onboarding concept previews

Selection recorded on 2026-09-24: the user approved **Option 1: Rising sheet**. Options 2 and 3 remain archived explorations. No application changes were made for this selection.

Implementation is governed by the [approved design contract](onboarding-redesign/design-contract.md) and [phased master tracker](onboarding-redesign/master.md). Original generation prompts below are historical reference, not implementation instructions.

Sources: canonical DESIGN.md, PRODUCT.md, questionnaire frontend-experience.md, current questions.tsx, and the supplied dark/pink reference. The requested sequential interaction takes precedence over older combined-form descriptions.

Shared flow: own answer → acceptable partner answers → importance → privacy and optional context → Save & continue.

Single choices advance after selection feedback. Multi-select has Continue. Importance uses named tap choices. Privacy and optional context appear in sequence. Back allows correction. Saving stays explicit and failed saves retain drafts. Reduced motion uses an instant transition or simple fade. Importance labels must be mapped to existing scoring semantics during implementation.

These are static image concepts illustrating proposed motion, not runnable animations.

## 1. Rising sheet

Use case: ui-mockup. Create a polished high fidelity design concept board for StrathSpace mobile dating onboarding, landscape image with FOUR complete readable phone screens side by side, showing successive moments of ONE question, and a clear concept title above. This is a visual inspiration preview, not code. Brand from project design docs: near-black #0D0B0D background, smoky subtle header, charcoal #151215 sheets and #1E1A1E controls, white text #F7F3F5, restrained hot pink #E0186A and pink text #FF5C97. SF Pro/system sans typography, generous breathing room, 56px tap rows, precise alignment, minimal icons. One pink filled action per phone, selected options use thin pink outline and checkmark. No sliders, no More menu, no stacks of forms, no Flareo name, no neon, no glassmorphism. Native status bars and safe areas. All text large and legible. Four phone states: 1 'How often would you like to hear from someone you’re dating?' choices 'Throughout the day' selected, 'A few times a day', 'Once a day', 'Whenever feels natural'. Helper 'Tap an answer to keep going'. 2 'What would work for you in a partner?' helper 'Choose all that feel right.' same four choices, first two selected; separate 'Any of these works' action; primary 'Continue'. 3 'How much does this matter?' three big clearly tappable options 'Not a big deal' / 'Nice to have' / 'Very important' with one-line plain-language descriptions, middle selected; tap proceeds automatically. 4 'Keep it private or share it?' options 'Keep private' and 'Show on my profile', private selected; caption 'Private answers still help with matching.' Visible optional text field 'Want to add a little context?' placeholder 'Add a note (optional)' and primary 'Save & continue'. Back available at every stage. Subtle overall chapter progress, no overwhelming 20-question counter. These four states represent a sequential flow, not four sections visible at once. Small annotation strip beneath phones describes motion. Title '01 / Rising sheet'. Closest to the attached user's black and pink reference. One grounded charcoal bottom sheet with rounded top corners fills most of each phone, brand name in smoky top region. Previous answer is a compact editable pill above current prompt. Sheet content changes instead of accumulating; show elevated sheet edges, friendly single tiny 3D speech-bubble motif on first screen. Centered headings. Footer annotation 'Tap → sheet changes → next small decision' and '220ms lift + fade'. Premium tactile dark mobile UI.
